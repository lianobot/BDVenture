# BDVenture

**BDVenture** is a 2D adventure game developed in **Java** as an Object-Oriented Programming project.

The project started as a small OOP game and has evolved into a more complete adventure experience, featuring exploration, combat, multiple maps, different player characters, and sound.

## About the Game

BDVenture is an adventure game where the player explores a dangerous world, encounters enemies, and fights their way through different areas.

The game focuses on combining simple exploration and combat mechanics with object-oriented programming concepts.

## Features

* 2D adventure gameplay
* Player movement and exploration
* Combat system
* Enemies and interactions
* Sound and audio effects
* Game resources and assets
* Object-oriented game architecture

## Built With

* **Java**
* **Object-Oriented Programming**
* **IntelliJ IDEA**
* Java-based game libraries and resources

## OOP Concepts

This project was created to apply concepts learned in Object-Oriented Programming, including:

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Object composition
* Methods and constructors
